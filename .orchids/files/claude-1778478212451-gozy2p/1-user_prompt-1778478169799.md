 Brief de refonte — OZ Connection

  1. Contexte

  Service basé à Melbourne (Naarm), Australie. Deux audiences en tension :
  - Public visible (funnel principal) : backpackers / Working Holiday / étudiants internationaux 18-30 (FR + EN). Tu
  vends des packs + des services à la carte pour préparer leur arrivée.
  - Public discret (canal B2B) : builders / tradies / entrepreneurs de Melbourne qui ont besoin de main d'œuvre fiable.
  Accessible via /pro, jamais dans la nav top, uniquement en footer + URL directe.

  Le slogan ancre tout : Parce qu'on est aussi passé par là. / Because we've been through it too. — décliné dans le
  hero.

  7. Animations & composants spéciaux

  Reveal (scroll-trigger fade+up)

  Framer Motion. Wrap autour de chaque bloc qu'on veut animer à l'apparition.

  variants: hidden { opacity:0, y:18 } → visible { opacity:1, y:0 }
  initial="hidden"
  whileInView="visible"
  viewport={ once: true, amount: 0.25 }
  transition={ duration: 0.7, ease: [0.16, 1, 0.3, 1], delay }

  Stagger via prop delay : 0.05, 0.1, 0.15, 0.18, 0.22, 0.28, 0.34, 0.4. Pas de Reveal pour les éléments hors viewport
  au load (perf).

  Marquee (horizontal infinite scroll)

  Pas Framer Motion. CSS keyframes pur (perf). Track dupliqué inline <div className="marquee-row">{children}</div> ×2.
  Animation marquee-scroll ${speed}s linear infinite avec transform: translateX(0) → translateX(-50%). Reverse via
  animation-direction: reverse. Mask gauche/droite linear-gradient pour fade des bords. @media (prefers-reduced-motion:
  reduce) { animation: none }.

  MagicCard (spotlight follow-cursor)

  Pas Framer Motion. onMouseMove met à jour --mx et --my CSS vars sur le ref. Deux pseudo-layers :
  1. Border gradient : radial-gradient(280px circle at var(--mx) var(--my), rgba(226,154,120,0.55), transparent 70%)
  masqué pour ne montrer que le 1px de bordure (WebkitMask: 'linear-gradient(#000 0 0) content-box, linear-gradient(#000
   0 0)', WebkitMaskComposite: 'xor').
  2. Spotlight glow : radial-gradient(360px circle at var(--mx) var(--my), var(--spotlight), transparent 60%).

  Les deux passent opacity 0 → 1 en 300ms au hover. Prop highlight change le border-gradient color (blanc 50% vs
  terra-300 55%).

  Spotlight (background SVG ellipse statique)

  SVG <svg viewBox=...> avec radialGradient fill. Position absolute, taille en %, opacité ~0.4-0.6. Animation pulse
  subtle via CSS animation: spotlight-pulse 6s ease-in-out infinite alternate. Couleurs : terra-500 ou terra-300 en hex.

  Sparkles

  Wrapper qui génère N particules absolute positionnées aléatoirement autour des children, chacune avec animation scale
  0 → 1 → 0 en boucle, delay random 0-3s. Abandonné dans le nouveau hero (le big orange title se suffit), mais
  utilisable autour de mots-clés.

  HoverEffect (FAQ cards)

  Liste de cards. Au hover sur une card, un layer absolute bg-ocean-600/8 apparaît avec layoutId Framer Motion pour
  glider depuis la card précédemment hover. C'est l'effet Aceternity classique.

  BentoGrid + BentoCell

  CSS grid. Cell prop span: 'large' | 'tall' | 'auto' mappe à lg:col-span-2, lg:row-span-2, ou rien. Prop variant:
  'feature' change fond → ocean-600 + texte sand. Index utilisé pour stagger Reveal delays.

  TextGenerateEffect

  Wrap autour d'une string. Split en mots, chaque mot apparaît avec un fade individuel quand le bloc entre en viewport.
  Framer Motion sequence avec staggerChildren: 0.04. Sert UNIQUEMENT pour le paragraphe lead de la section Problem.

  WorldMap

  SVG monde stylisé en grille de dots (genre Magic UI WorldMap). Plusieurs <path> reliant Naarm/Melbourne (origin) à 5-6
   villes (Paris, Sydney, London, Berlin, Madrid, etc.) avec stroke animé : strokeDasharray: 0 1000 → 1000 0 sur 2s,
  infinite repeat. Cercles aux extrémités (r=9 + r=3.6). Couleur stroke + fill terra-500 #ED6A1F.

  ShimmerButton

  Bouton avec couche shimmer qui traverse (CSS animation from translateX(-100%) to translateX(100%) sur 2.5s linear
  infinite). Utilisé uniquement dans Final CTA.

  GridPattern

  SVG pattern dots ou grille, opacity 0.04-0.07, couleur ocean-400 ou sand-100. Sert à donner de la texture aux sections
   plates.

  8. Règles de copy (strict)

  Ne rien inventer. Chaque ligne doit être :
  - ✓ EXACT (validée par le founder / déjà publiée),
  - ✓ CDC (extrapolation directe et non-disputable du cahier des charges),
  - ⚠ NEUTRE (formulation prudente sans claim non vérifiable),
  - 📝 TBD (placeholder visible en attente de validation).

  Interdits sans validation explicite : prix, délais (sous 24h, en 48h), garanties (anglais garanti, disponibilité
  demain), parcours founder, années d'expérience, taux de placement, certifications.

  📝TBD doit rester visible dans le rendu, pas masqué — c'est ce qui force le founder à valider avant prod. Format : 📝
  TBD — [ce qu'il manque].

  9. Disclaimer non-négociable

  Footer + page Legal doivent porter cette mention exacte :

  ▎ OZ Connection n'est PAS un agent de migration enregistré (OMARA), n'est PAS une école, n'est PAS une banque, n'est
  ▎ PAS un agent fiscal (Tax Practitioners Board), n'est PAS une agence de placement, n'est PAS un employeur. Service
  ▎ d'orientation et d'accompagnement uniquement.

  Idem dans les excludes de chaque service à la carte ("Pas un X — c'est toi qui fais Y") et sur /pro ("Pas une agence
  d'intérim, pas un employeur, pas de mandat sur les candidats").
