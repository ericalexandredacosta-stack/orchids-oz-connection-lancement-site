# OZ Connection — Website Redesign Prompt
> For use with Cursor, v0, Bolt, Framer AI, or any website-building AI tool.

---

## Context

You are rebuilding the website for **OZ Connection** (oz-connection.com), a Melbourne-based arrival support service for backpackers and international students starting their life in Australia. The service was built by Paul, a French expat with 8+ years of experience living and working in Melbourne.

The existing website has strong content and a distinctive design system, but suffers from a single overcrowded page. The goal of this redesign is to **restructure into 4 pages** while preserving the design system exactly and improving the narrative flow.

## Design System — Preserve Exactly

### Colors
```css
--color-primary: #F5A623;       /* Orange — primary brand, CTAs, accents */
--color-primary-dark: #E09000;  /* Orange darker — hover states */
--color-dark-bg: #0F1923;       /* Near-black — dark sections background */
--color-dark-surface: #1A2633;  /* Slightly lighter — cards on dark bg */
--color-light-bg: #FDF6EE;      /* Warm off-white — light sections */
--color-light-surface: #FFFFFF; /* White — cards on light bg */
--color-text-dark: #0F1923;     /* Body text on light bg */
--color-text-light: #FFFFFF;    /* Body text on dark bg */
--color-text-muted: #6B7280;    /* Secondary text */
--color-success: #22C55E;       /* Checkmarks, included features */
```

### Typography
```css
/* Display headings — large, bold, impactful */
font-family: 'Syne', sans-serif;   /* or equivalent bold display font */
font-weight: 800;

/* Body and UI */
font-family: 'Inter', sans-serif;
font-weight: 400 / 500 / 600;

/* Key typographic rules from original site: */
/* - Hero headings: 72–80px, weight 800, orange color (#F5A623) */
/* - Section headings: 40–52px, weight 800, dark navy */
/* - Subheadings in orange: 16px, weight 600, uppercase tracking */
/* - Body: 16–18px, weight 400, line-height 1.7 */
/* - Small labels/badges: 11–12px, uppercase, letter-spacing 0.1em */
```

### Components to reuse

**Navigation bar**
- Logo left: sun icon (orange) + "OZ" (orange, bold) + "Connection" (dark, regular)
- Nav links center: PACKAGES · COMPARE · HOW IT WORKS · ABOUT · FAQ
- Right: "FR Français" language toggle (outlined pill) + "WHATSAPP" button (orange, rounded, with chat bubble icon)
- Transparent on hero, solid `--color-dark-bg` on scroll

**Buttons**
```
Primary CTA:   bg #F5A623, text #0F1923, font-weight 700, rounded-full, padding 14px 28px
               Icon: chat bubble (WhatsApp style) on left
Secondary CTA: bg transparent, border 2px solid white, text white, same padding
               Arrow → icon on right
Tertiary CTA:  outlined, border #F5A623, text #F5A623, on light backgrounds
```

**Badge / Label pills**
```
Section label:  border 1px solid #F5A623, text #F5A623, bg transparent,
                font-size 11px, uppercase, letter-spacing 0.1em, rounded-full
                Examples: "OUR PACKAGES" · "HOW IT WORKS" · "WHY OZ CONNECTION"

Feature badge:  bg #F5A623, text #0F1923, font-size 11px, font-weight 700
                Examples: "MOST POPULAR" · "LAUNCH PRICE" · "MOST SUPPORTED"

Info badge:     bg transparent, border 1px dashed #6B7280, text #6B7280
                Example: "add-on" in comparison table
```

**Decorative dot**
- Small orange circle (8–10px), solid fill `#F5A623`, used as floating accent element
- Placed in section corners or near headings as visual rhythm device

**Section alternation pattern**
- Light sections: `background: #FDF6EE`, text dark
- Dark sections: `background: #0F1923`, text white, orange accents
- Alternate consistently: Light → Dark → Light → Dark

**Checkmark list items**
- Icon: ✓ in `#F5A623` (light sections) or `#22C55E` (dark sections / included features)
- Text: 15px, font-weight 500

**Cards (pricing)**
```
Light card:  bg white, border 1px solid #E5E7EB, border-radius 16px, padding 32px
Dark card:   bg #1A2633, border 1px solid #2D3F50, border-radius 16px, padding 32px
             "MOST POPULAR" card: slightly larger, dark bg even in light sections
```

**Comparison table**
- Feature rows alternate: white / `#F9F6F2`
- Check icons: orange (included in lower packs), green (included in higher packs)
- Dash (—): muted gray for not included
- Duration badges inline: "48h", "2 weeks", "1 month" — small orange pill

**Step numbers**
- Square with rounded corners, bg `#F5A623`, text `#0F1923`, font-weight 800
- Size: 48×48px, border-radius 10px
- Used in "How it works" and "Why Melbourne" sections

**Image cards** (used in About and Why Melbourne sections)
- Rounded corners (20px), overflow hidden
- Bottom-left caption: small white text on dark overlay
- Optional floating info card: white card overlapping bottom of image, with green dot + bold title + subtitle

- Language switcher (EN / FR) should be wired to a French version of each page
- Smooth scroll between anchor sections
- Lazy load images
- The hero slider (3 dots visible) implies multiple background images — implement as auto-rotating carousel with 4s interval
